### מעבר לדרישות המינימום

* **מתג עברית/אנגלית** — כל טקסט קיים בעמוד בשתי שפות, וכיוון הכתיבה מתהפך בין RTL ל-LTR. גם הוא ב-CSS בלבד.
* **מקטעים נוספים** — כישורים טכניים עם מדדי רמה, פרויקטים נבחרים, וציר זמן של השכלה וניסיון.
* **נגישות** — קישור דילוג לתוכן, שמות נגישים לכל מקטע, מיקוד מקלדת נראה, אייקונים דקורטיביים מוסתרים מקוראי מסך, וכיבוד `prefers-reduced-motion`.
* **ניגודיות** — שתי ערכות הצבעים עומדות בתקן WCAG AA (נבדק אוטומטית, ראו בהמשך).
* **גיליון הדפסה** — הדפסת העמוד מייצרת קורות חיים נקיים על נייר לבן.
* **אנימציית גלילה** — מקטעים נחשפים בגלילה בעזרת `animation-timeline`, עטוף ב-`@supports` כדי שדפדפנים ישנים יציגו הכול כרגיל.
* **פרטי מטא** — תגיות Open Graph, `canonical`, ו-favicon.

## איך עובד מצב כהה בלי JavaScript

שלושה שדות קלט מוסתרים יושבים בראש `<body>`, לפני עוטף התוכן `.page`:

```html
<input class="switch" type="checkbox" id="theme-switch">
<input class="switch" type="radio" name="site-lang" id="lang-he" checked>
<input class="switch" type="radio" name="site-lang" id="lang-en">
<div class="page"> ... </div>
```

תוויות `<label for="...">` בסרגל העליון משמשות ככפתורים. כשמשנים את מצב הקלט, ה-CSS מגיב דרך **סלקטור האחים הכללי** ומחליף את כל ערכת המשתנים:

```css
#theme-switch:checked ~ .page { --bg: #080b17; --fg: #c5ccdd; /* ... */ }
#lang-en:checked    ~ .page { direction: ltr; }
#lang-en:checked    ~ .page .he { display: none; }
```

השדות עצמם מוסתרים ויזואלית אך נשארים ממוקדים במקלדת, כך שאפשר להפעיל את המתגים ב-Tab + רווח.

> הערה: ללא JavaScript אין דרך לשמור את הבחירה בין טעינות עמוד — זהו מחיר מובנה של המגבלה שהוגדרה במטלה.

## אימות

לפני ההגשה האתר נבדק בשלוש דרכים:

* **ולידטור ה-HTML הרשמי של W3C** — 0 שגיאות ו-0 אזהרות.
* **רינדור בפועל ב-Chrome** ברוחבי 320, 360, 390, 430, 768, 900 ו-1280 פיקסלים,
  בשני מצבי התצוגה ובשתי השפות — ללא גלישה אופקית באף רוחב.
* **חבילת בדיקות אוטומטית** שנכתבה במהלך הפיתוח וכיסתה 65 תנאים: היעדר
  JavaScript ועיצוב מוטבע, קיום כל הקישורים הנדרשים, שכל עוגן וכל קובץ מקומי
  אכן קיימים, היררכיית כותרות רציפה, מזהים ייחודיים, התאמה מלאה בין כל מחרוזת
  עברית לאנגלית, ויחס ניגודיות WCAG AA לכל זוג טקסט/רקע בשתי ערכות הצבעים.
  כלי הבדיקה אינו חלק מהאתר ואינו נכלל בהגשה.
