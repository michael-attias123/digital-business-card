01 · הכירו אותי01 · Get to know me

עלייAbout me

שמי מיכאל, סטודנט שנה ג' למדעי המחשב במכללה למנהל ומהנדס DevOps עם למעלה מחמש שנות ניסיון מעשי. ביום-יום אני בונה ומתחזק תשתיות ענן, צינורות CI/CD ואוטומציה שמקצרת פריסות מימים לדקות. בשנים האחרונות התחום שמרתק אותי במיוחד הוא למידה עמוקה, ואני עובד בדיוק על התפר שבין השניים: לקחת מודל שרץ במחברת Jupyter ולהפוך אותו לשירות יציב, מנוטר ומדיד שרץ בענן. בין הפרויקטים שבניתי — פלטפורמת MLOps מקצה לקצה, צינור עיבוד Big Data בזמן אמת, ותשתית ענן מלאה המנוהלת כקוד. אני מחפש תפקיד שמחבר בין הנדסת תשתיות ללמידת מכונה, ומאמין שקוד טוב הוא קוד שגם מישהו אחר יכול לתחזק. I'm Michael, a third-year Computer Science student at the College of Management and a DevOps engineer with over five years of hands-on experience. Day to day I build and maintain cloud infrastructure, CI/CD pipelines and automation that cuts deployments from days to minutes. In recent years the field that fascinates me most is deep learning, and I work exactly at the seam between the two: taking a model that runs in a Jupyter notebook and turning it into a stable, monitored, measurable service in the cloud. Among the projects I've built — an end-to-end MLOps platform, a real-time big-data pipeline, and a full cloud infrastructure managed as code. I'm looking for a role that connects infrastructure engineering with machine learning, and I believe good code is code someone else can maintain too.

    תכנון והקמה של סביבות AWS מאובטחות ומדרגיות, מנוהלות כקוד מהיום הראשון. Designing and building secure, scalable AWS environments, managed as code from day one.

  • אוטומציה ו-CI/CDAutomation & CI/CD

    צינורות בנייה ופריסה אוטומטיים, בדיקות בכל commit והחזרה לאחור בלחיצה אחת. Automated build and deploy pipelines, tests on every commit and one-click rollbacks.

  • למידה עמוקהDeep learning

    מהאימון ועד הפרודקשן: רשתות נוירונים, מעקב ניסויים והגשת מודלים בזמן אמת. From training to production: neural networks, experiment tracking and real-time model serving.

03 · מה בניתי03 · What I've built

פרויקטים נבחריםSelected projects

שלושה פרויקטים שמסכמים את מה שאני הכי אוהב לעשות: לחבר בין נתונים, תשתית ומודלים. Three projects that sum up what I love doing most: connecting data, infrastructure and models.

01

MLOps Pipeline

פלטפורמה מקצה לקצה שלוקחת מודל מ-commit בגיט ועד שירות חי בענן — אימון, מעקב ניסויים, ניהול גרסאות והגשה אוטומטית. An end-to-end platform that takes a model from a git commit to a live cloud service — training, experiment tracking, versioning and automated serving.

מה מעניין בוWhat makes it interesting
  • אימון אוטומטי בכל דחיפה לענף הראשי, עם השוואת מדדים מול המודל שכבר בפרודקשן.Automatic training on every push to the main branch, comparing metrics against the model already in production.
  • רישום גרסאות מודל ב-MLflow ופריסה הדרגתית מסוג Canary לאשכול Kubernetes.Model version registry in MLflow and gradual canary rollouts to a Kubernetes cluster.
  • ניטור סחיפה בנתונים עם התראה אוטומטית כשאיכות התחזיות יורדת.Data-drift monitoring with automatic alerts when prediction quality drops.
  • Python
  • PyTorch
  • MLflow
  • Docker
  • Kubernetes
  • GitHub Actions
02

Cloud Infrastructure as Code

תשתית AWS שלמה שקמה בפקודה אחת: רשת, אשכול EKS, בסיסי נתונים וניטור — הכול מתואר בקוד ונשמר בגיט. A complete AWS environment provisioned with a single command: networking, an EKS cluster, databases and monitoring — all described as code and kept in git.

מה מעניין בוWhat makes it interesting
  • הקמת סביבה חדשה (פיתוח, בדיקות או פרודקשן) בפחות מרבע שעה במקום יומיים.Spinning up a new environment (dev, staging or production) in under fifteen minutes instead of two days.
  • מודולים חוזרים ב-Terraform, עם תוכנית שינויים שעוברת בדיקה לפני כל החלה.Reusable Terraform modules, with a change plan that is reviewed before every apply.
  • לוחות ניטור ב-Grafana והתראות ב-Prometheus שנוצרים יחד עם הסביבה.Grafana dashboards and Prometheus alerts created together with the environment itself.
  • Terraform
  • AWS
  • EKS
  • Helm
  • Prometheus

03

Real-Time Stream Analytics

צינור עיבוד נתונים בזמן אמת שקולט מיליוני אירועים ביום, מנקה, מצרף ומזהה אנומליות תוך שניות. A real-time data pipeline that ingests millions of events a day, then cleans, aggregates and detects anomalies within seconds.

מה מעניין בוWhat makes it interesting
  • קליטת אירועים ב-Kafka ועיבוד חלונות זמן ב-Spark Structured Streaming.Event ingestion through Kafka and time-window processing in Spark Structured Streaming.
  • תזמון וניהול תלויות של משימות ה-ETL באמצעות Airflow, כולל ניסיון חוזר אוטומטי.Scheduling and dependency management for the ETL jobs with Airflow, including automatic retries.
  • זיהוי אנומליות סטטיסטי שמתריע על חריגות לפני שהן מגיעות למשתמשים.Statistical anomaly detection that raises a flag before irregularities reach users.

  • Apache Spark

  • PostgreSQL
